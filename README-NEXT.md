# Тихая долина — Next.js / PostgreSQL

Полный исходник основной версии игры: App Router, React, PostgreSQL через Drizzle ORM, мобильная ферма, социальные функции, кооперативы, работники, сезонный пропуск, рейтинги и расширенная админка.

## Запуск
```bash
npm install
cp .env.example .env
# Укажите DATABASE_URL в .env
npx drizzle-kit push
npm run build
npm run start
```

Для создания администратора:
```bash
node scripts/create-admin.mjs admin 'смените-этот-пароль'
```

Админка: `/admin`. Вход в игру и админку общий, через httpOnly-сессию.

## Проверка
```bash
npx next typegen
npm exec tsc -- --noEmit --pretty false
npm run build
```

## Графика и контент
Разделы админки «Дизайн», «Контент игры», «Баланс» и «Бонусы» работают с PostgreSQL. Все SVG-иконки имеют ключи `svg:<имя>` и могут быть заменены своей картинкой. Пользовательские изображения хранятся в таблице `assets` и отдаются через `/api/asset/<ключ>`.

## PHP/MySQL/AJAX/Canvas-версия

Автономный PHP-пакет лежит в `php/`, готовые раздельные архивы собираются в `downloads/`. В админке Next.js откройте
«Экспорт»: там обе версии и кнопка «Обновить архивы» (`POST /api/admin/export`).

- `valley-next.zip`: **только исходники Next.js + PostgreSQL** (React, App Router, Drizzle, `public/images/`). PHP-файлов в нём нет.
- `valley-php.zip`: **только автономный PHP/MySQL-сайт**. `install.php`, `index.php`, `assets/` и `images/` находятся в корне архива. Исходники Next.js и `next-source/` не включены.

Если вы разворачиваете только Next.js-архив, PHP-исходников в нём нет: отдельный `valley-php.zip` можно положить в каталог `downloads/` вручную. Пересборка Next.js не затронет загруженный PHP ZIP. Если вы разворачиваете только PHP-архив, PHP-админка сможет пересобрать его при наличии `php-zip`; для скачивания Next.js отдельно загрузите `valley-next.zip` или используйте основную админку.

PHP-версия использует общий собранный интерфейс, PDO/MySQL, серверные игровые правила и `password_hash()`. Node.js на PHP-хостинге не нужен.

**Установка:** загрузите содержимое PHP-архива на сайт и откройте `install.php`. Мастер сам подключится к MySQL, создаёт базу при наличии права CREATE (или использует существующую), импортирует все 38 SQL-запросов, проверяет 31 таблицу и начальные данные, создаёт администратора и атомарно сохраняет `config.local.php`. Ручной импорт через phpMyAdmin не требуется. При закрытом корне сайта используется `data/config.local.php`; если запись запрещена везде, мастер предложит скачать готовый конфиг. Повторный запуск не удаляет прогресс и не меняет пароль администратора без явного выбора.

Подробности, права MySQL, CLI и решение ошибок — `php/README-PHP.md`.

Пересборка клиента и обоих архивов из текущего кода:
```bash
node scripts/build-downloads.mjs
```

Проверки установщика и PHP-пакета:
```bash
node php/tests/static.mjs
php php/tests/installer-unit.php
VALLEY_TEST_DB_NAME=valley_installer_test VALLEY_TEST_DB_USER=test_user VALLEY_TEST_DB_PASSWORD='test-password' node php/tests/installer-http.mjs
```

HTTP-тест сам запускает временный PHP-сервер на пустой одноразовой базе, проверяет установку, конфиг, вход, лотереи, регистрацию и сохранение прогресса, затем останавливает сервер. Он не удаляет тестовую базу. Подробные параметры — `php/tests/README.md`.

Секреты, `config.local.php`, `data/config.local.php`, временные файлы установщика, `.env` и данные игроков в архивы не включаются. Для переноса прогресса сделайте резервную копию базы отдельно.

## Стройка, техника и лотереи (обе версии)

- **Постройки:** амбар, грядки (+2 грядки за уровень) и водоём (+1 пруд) строятся за монеты **и руду**
  из шахт. Каждый уровень дороже: цена = `coinBase × coinMult^(уровень−1)` и `oreBase × oreMult^(уровень−1)`.
  Базы, множители, руда и максимальный уровень задаются в админке: «Лотереи и стройка» / `POST /api/admin/extras`.
- **Техника:** кормушки (`feeder`, +8% скорости и +1 продукт за 2 уровня), комбайн (`harvester`,
  сбор урожая одним нажатием и +10% опыта за уровень), аэратор (`aerator`, −10% времени роста за уровень).
- **Лотереи:** таблицы `lotteries` и `lottery_entries`, несколько лотерей по умолчанию, шансы призов
  задаются весами в админке, розыгрыш и начисление призов — на сервере (`/api/lottery`).
  В PHP-версии те же таблицы и логика (`php/lib/engine.php`, `php/api.php`).
- **Векторная графика:** все эмодзи заменены на инлайновые SVG-иконки: в Next.js — lucide-react,
  в PHP — собственная библиотека `UI_PATHS`/`SHAPES` с отрисовкой форм и на Canvas.

## Рыбалка, рейтинги и новая защита фермы

- Между забросами теперь **2 минуты 30 секунд**. Пауза начинается при забросе, сохраняется после удачной или неудачной подсечки и проверяется сервером. Таймер виден в разделе «Водоёмы → Рыбалка».
- Рейтинги показывают всех незаблокированных участников, включая игроков с нулём очков.Своё место закреплено отдельно; администраторы отмечены и не участвуют в раздаче призов. All-time ranking uses total XP, not only XP within the current level. Loading errors offer retry.
- Основной игровой текст, подписи и кнопки увеличены; компактная типографика админки сохранена.
- «Растения против зомби» использует 32 растровых PNG-спрайта без эмодзи и SVG. Добавлены двойной/тройной горох, крепость-орех, колючая трава, картофельная мина, капустомёт и кабачок-страж. На телефоне клетки около 92 px в режиме «Крупно ×2», поле прокручивается пальцем; есть полный экран, пауза и подсветка клетки.

Проверки: `node scripts/test-defense-engine.mjs`, `node scripts/test-php-engine.mjs`, `node scripts/test-refinements-api.mjs`, `node scripts/test-refinements-ui.mjs`. HTTP/UI-тесты принимают `TEST_URL`, `TEST_TAG`, `TEST_ADMIN_USER`, `TEST_ADMIN_PASSWORD`; запускайте их только на тестовой базе.
